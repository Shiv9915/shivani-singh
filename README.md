# Shivani Singh | Portfolio

A responsive personal portfolio website built with plain **HTML, CSS and JavaScript**. It presents my skills, projects, internships and education as a Full Stack Developer.

## Live Demo

[View the portfolio](https://your-live-link-here)

## Features

- Responsive layout for mobile and desktop
- Light and dark theme toggle, remembered between visits
- Animated role text in the hero section
- Skills section with category filters
- Scroll-reveal animations
- Sections: About, Skills, Projects, Experience, Education, Contact
- No frameworks or build step

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- JavaScript (ES6)

- **GitHub Pages:** Settings → Pages → select the `main` branch → Save
- **Vercel / Netlify:** import the repository and deploy (no build command needed)
